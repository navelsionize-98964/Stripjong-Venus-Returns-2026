## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Stripjong - Super Real Mahjong Venus Returns**. This trainer is built around the game's turn-based mahjong structure. It lets you control score pressure, prevent losses, and clear routes with far less grind, while keeping the match flow focused on progression and unlocks.

**Target Audience:** Players who want to experience the mahjong routes, character scenes, and unlocks without repeated losses or long progression grind.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Infinite Score** — Locks your score at a favorable level during matches so you can play through rounds without falling behind.
- **Always Winning Hand** — Keeps hand outcomes tilted in your favor so you can finish rounds cleanly instead of relying on defensive play.
- **Freeze Timer** — Stops time pressure in modes that use timed decisions, giving you room to read the table and choose tiles calmly.

### ⚔️ Combat

- **Opponents Cannot Win** — Prevents the table from turning against you by blocking enemy wins and preserving a safe match state.

### 📌 Progression

- **Unlock All Scenes** — Opens reward scenes and route progress so you can access the game's content without replaying every branch.

There is no free movement. Navigation happens through menu selection, dialogue prompts, and the flow between matches.

The match table is the core challenge. Build valid mahjong hands, call tiles when useful, declare riichi, and win rounds to push the game forward.
